# 🎨 Центр Красок #1 — Telegram AI-бот

Telegram-бот с AI-ассистентом, который отвечает на вопросы о компании **Центр Красок #1** на основе собранной базы знаний.

## Стек
- **Python 3.10+**
- **python-telegram-bot** — Telegram Bot API
- **Anthropic Claude** — AI-модель (claude-sonnet-4)
- **Railway** — деплой (бесплатно)

---

## Быстрый старт

### 1. Получи токены

**Telegram-бот:**
1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`, придумай имя и username
3. Скопируй токен

**Anthropic API:**
1. Зарегистрируйся на [console.anthropic.com](https://console.anthropic.com)
2. Перейди в API Keys → Create Key
3. Скопируй ключ

---

### 2. Локальный запуск

```bash
# Клонируй / распакуй проект
cd centr_krasok_bot

# Установи зависимости
pip install -r requirements.txt

# Создай файл .env
cp .env.example .env
# Открой .env и вставь свои токены

# Запусти
python bot.py
```

Для автозагрузки `.env` установи `python-dotenv`:
```bash
pip install python-dotenv
```
И добавь в начало `bot.py`:
```python
from dotenv import load_dotenv
load_dotenv()
```

---

### 3. Деплой на Railway (бесплатно, рекомендуется)

1. Зарегистрируйся на [railway.app](https://railway.app)
2. Нажми **New Project → Deploy from GitHub** (или загрузи файлы через CLI)
3. В разделе **Variables** добавь:
   - `TELEGRAM_BOT_TOKEN` = твой токен
   - `ANTHROPIC_API_KEY` = твой ключ
4. Railway автоматически запустит `Procfile` → `python bot.py`

## Как работает бот

1. Пользователь пишет **любое текстовое сообщение** (без команд/меню)
2. Бот отправляет запрос в **Claude API** с системным промптом, содержащим всю базу знаний
3. Модель отвечает **строго на основе базы знаний**, без галлюцинаций
4. **История диалога** хранится в памяти (последние 10 пар сообщений на пользователя)
5. Если вопрос не по теме — бот вежливо переводит на профильные вопросы

---

## Защита от галлюцинаций

В системном промпте явно указано:
- Отвечать **только на основе базы знаний**
- При отсутствии информации — **направлять на менеджера**
- Не придумывать несуществующие товары, цены, акции

## Масштабирование

Для хранения истории между перезапусками замени `defaultdict` на **Redis**:
```bash
pip install redis
```
```python
import redis
r = redis.from_url(os.environ["REDIS_URL"])
# Сохранять/загружать историю через r.get/r.set с JSON-сериализацией
```
Railway поддерживает Redis-плагин прямо в проекте.
